# Evaluating AI systems

## Evaluation criterias

1. Domain specific capability     
2. Generation capability    
3. Instruction following capability       
4. Cost and Latency       

### Domain Specific Capability

Does your model (chosen) has the requried domain knowledge to build AI application?

Evaluation approach: Close ended approach is used. Model is provided with multiple MCQs     
to respond. How many does it get right is used as a metric (**accuracy metric**)
