# Agentic AI Notes

Anthropic has defined 2 types of systems in the AI era:   

1. **Workflows**: LLM calls and tools are orchestrated through pre-defined code paths.   
2. **Agents**: LLMs dynamically decide paths, maintaining control over how they accomplish tasks.
